# The Open TableTop Initiative (OTI)

Welcome to the official home of the **Universal Virtual Tabletop Specification (UVTT v2)**.

UVTT v2 is a modern, performant, and extensible system-neutral open specification for TTRPG campaign map data. It replaces legacy, flat-plane, single-file geometries with a multi-layered, topologically aware relational spatial database framework.
