# 📂 UVTT v2 Core Schemas

Welcome to the Open Virtual Tabletop Consortium schema directory. These JSON Draft-07 schemas strictly define the data structures required for UVTT v2 compliance.

### 🔗 Schema Definitions

- **[Manifest & Metadata](manifest.schema.json)** (`manifest.schema.json`): Defines global campaign metadata, grid topology, and the required ZKS/Web Crypto extensions.
- **[Geometry & Topology](geometry.schema.json)** (`geometry.schema.json`): Defines vector lines, curves, lighting boundaries, and elevation properties.
- **[Entities & Spawns](entities.schema.json)** (`entities.schema.json`): Defines dynamic tabletop objects including lights, audio emitters, and interactive events.
- **[Assets](assets.schema.json)** (`entities.schema.json`): Defines props, tokens, audio files, emitter artifacts et al.
