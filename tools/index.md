# 🧰 Official Consortium Tools

Welcome to the UVTT v2 toolchain directory. This folder contains official, zero-dependency command-line interfaces (CLIs) and packaging utilities designed to help developers build, sign, and compile UVTT v2 assets.

### 🛠️ Available Tooling

- **Verification Wrapper (`verify-all.sh`):** The unified bash script for executing local environment audits and ZKS handshake tests.
- **generate-mock-uvtt2z.py**
- **pre-commit:** Git Pre-Commit Hook
